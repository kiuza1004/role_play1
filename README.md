# ⚔️ Lineage Classic 3D Mobile (리니지 1 클래식 3D 모바일)

> 1998년 클래식 리니지(말하는 섬 에피소드)의 감성과 조작감을 웹 및 모바일 브라우저에 그대로 구현하고, Three.js 기반의 웅장한 3D 입체 그래픽스 및 실시간 동적 조명/그림자 시스템으로 혁신한 3D MMORPG입니다.

* **실행 링크**: [https://kiuza1004.github.io/role_play1/](https://kiuza1004.github.io/role_play1/)
* **현재 버전**: `v2.0.0` (Full 3D Epic Graphics Edition - 입체감 & 볼륨감 대격변)

---

## 📖 게임 완전 공략 설명서

### 1. 조작법 안내
| 액션 | 모바일 (스마트폰) | PC 브라우저 |
| :--- | :--- | :--- |
| **이동** | 가고자 하는 바닥 터치 | 마우스 좌클릭 |
| **공격 (타겟팅)** | 몬스터 또는 허수아비 터치 | 마우스 좌클릭 타겟 지정 |
| **물약 빠른 복용** | 하단 F1(빨간물약) 터치 | 마우스 우클릭 또는 `F1` / `1` |
| **단축 슬롯 사용** | 하단 F1~F8 슬롯 터치 | 키보드 `F1` ~ `F8` 또는 `1` ~ `8` |
| **인벤토리 / 상태창** | 상단 `[가방]` / `[정보]` 터치 | 키보드 `I` / `C` |

### 2. 단축창 (F1 ~ F8) 아이템 일람
1. **F1 (빨간 물약)**: 복용 즉시 체력(HP)을 회복합니다.
2. **F2 (초록 물약)**: 30초 동안 이동속도와 공격속도가 상승하는 1단 가속 상태가 됩니다.
3. **F3 (용기의 물약)**: 기사 전용 2단 가속 아이템으로 검을 휘두르는 속도가 폭풍처럼 빨라집니다.
4. **F4 (순간이동 주문서)**: 필드 내 임의의 안전한 좌표로 순간 텔레포트합니다.
5. **F5 (귀환 주문서)**: 위기 상황 시 말하는 섬 마을 안전지대로 즉시 귀환합니다.
6. **F6 (무기 마법 주문서 - 데이)**: 착용 무기의 인챈트 강화를 시도합니다.
7. **F7 (변신 주문서 - 데스나이트)**: 45초 동안 전설의 52레벨 데스나이트로 변신하여 압도적인 공속으로 칼질합니다.
8. **F8 (에너지 볼트)**: MP 10을 소모하여 지정된 대상에게 원거리 마법 탄환을 발사합니다.

---

### 3. 무기 인챈트(데이) 확률 시스템
* **+0 ~ +5**: 100% 안전 인챈트 성공 (공격력 단계별 대폭 상승)
* **+6 이상**: 고위험 고수익 확률 인챈트
  * 쉬움 모드: 80% 성공
  * 보통(클래식) 모드: 65% 성공 / 35% 증발 파괴
  * 어려움 모드: 50% 성공 / 50% 증발 파괴
  * *실패 시 무기가 증발하여 0강으로 리셋됩니다.*

---

### 4. 속도 및 난이도 조절 (상단 [⚙ 설정] 메뉴)
* **게임 배속**: `1.0x (표준)`, `1.5x (빠름)`, `2.0x (초고속)` 자유 선택 가능
* **게임 난이도**:
  * **쉬움 (초보)**: 몬스터 공격력 40% 감소, 물약 회복량 및 획득 경험치 대폭 증가, 인챈트 성공률 80%
  * **보통 (클래식)**: 원작 리니지 표준 밸런스
  * **어려움 (하드)**: 몬스터 공격력 45% 및 체력 35% 증가, 인챈트 성공률 50%
